# A birthday card for Kela

A small, interactive birthday card made with plain HTML, CSS, and JavaScript. Open `index.html` in a browser, then tap the envelope. No install or build step is needed.

To refresh the published files after editing, run `node build.mjs` from this folder. This copies the card into `dist/`.

## Make it personal

- Edit the letter text in `index.html` inside `<section class="letter">`.
- Edit the sender line in `.letter__bottom` (`made just for you`).
- Change the colors at the top of `style.css`.

The page works on phones and desktop. It supports keyboard use and reduced-motion settings.
